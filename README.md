# Jazar demo

A phone-friendly mockup of Jazar, an offline Arabic–Malay dictionary.

Live: https://jazar-demo.pages.dev/

- Sample data from the Jazar trial database; Malay meanings are drafts still under review.
- Every Arabic word, form and search result shown comes from the Jazar engine.
